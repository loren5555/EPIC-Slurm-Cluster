# 网络与静态地址规划

本页是 EPIC 集群内部组网和地址分配的当前维护约定。新增节点、替换设备或配置临时
主机前，先在此确认拓扑和可用范围；实际固定租约、主机名和网卡 MAC 地址应在本页
及项目 inventory 中保持一致。

## 当前拓扑

```text
校园网
  │
  ├── DHCP / 校园网认证
  │
epic-cluster-controller-01
  ├── 校园网口：校园网地址和系统唯一默认路由
  └── 集群网口：192.168.77.251/24
          │
          └── 企业路由器 LAN 交换平面
                  ├── 管理地址：192.168.77.1/24
                  ├── DHCP、固定租约、网关和 DNS 下发
                  ├── LAN 口直连计算节点
                  └── LAN 口连接二层交换机后扩展计算节点
```

企业路由器的 WAN 口不连接，也不承担互联网出口 NAT。路由器 LAN 口、下游交换机和
所有内部主机位于同一个二层广播域；计算节点可以直连路由器 LAN 口，也可以通过二层
交换机接入，二者网络行为相同。

## 网络约定

- 集群内部 IPv4 子网为 `192.168.77.0/24`。
- 新控制节点 `epic-cluster-controller-01` 的集群网口为
  `192.168.77.251/24`，也是内部服务器的默认网关。
- 企业路由器开启 DHCP。正式服务器保持 DHCP 客户端配置，由路由器按网卡 MAC 下发
  固定租约；临时设备从独立的动态地址池获取地址。
- DHCP 统一下发默认网关 `192.168.77.251`，DNS 使用当前 VLAN 约定的 `8.8.8.8`
  和 `114.114.114.114`。
- 校园网侧只直接服务控制节点；计算节点不配置校园网地址或第二条默认路由。

## 外网数据路径

```text
计算节点
  → 默认网关 192.168.77.251
  → 控制节点 IPv4 forwarding
  → nftables masquerade
  → 控制节点校园网口
  → 校园网和互联网
```

控制节点允许内网主动访问校园网，并允许连接跟踪识别的返回流量；不把校园网入站
连接转发到计算节点。2026-09-02 从自由计算节点实测，公网路由第一跳为
`192.168.77.251`，第二跳进入校园网，公网 IP、DNS 和 HTTPS 均可访问。

## 分配规则

1. 根据节点用途从对应固定租约地址段选择地址，不从动态地址池选择正式服务器地址。
2. 分配前检查路由器租约、inventory 和目标广播域，确认地址没有被占用。
3. 在路由器中绑定稳定主机名、固定地址和网卡 MAC；Linux 主机保持 DHCP 客户端配置。
4. 固定租约变更后，客户端可能在当前租约到期前继续使用原动态地址。更新租约或重新
   连接网络后，再确认地址、`/24` 掩码、`.251` 默认网关和 VLAN DNS 均已生效；该过渡
   状态不视为链路故障。
5. 使用预留地址或调整任何范围时，必须先更新本页，再修改设备配置和 inventory。
