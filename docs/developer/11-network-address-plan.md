# 网络与静态地址规划

本页是 EPIC 集群内部网络和地址分配的当前维护约定。新增节点、替换设备或配置临时
主机前，先在此确认可用范围；实际固定地址、主机名和网卡 MAC 地址仍应记录在项目
inventory 中。

## 网络约定

- 集群内部 IPv4 子网为 `192.168.77.0/24`。
- 新控制节点 `epic-cluster-controller-01` 的集群网口为
  `192.168.77.251/24`，也是内部服务器的默认网关。
- 正式服务器使用静态地址，不依赖 DHCP 租约维持 Slurm 通信。
- 临时设备使用独立 DHCP 地址池，不得占用静态地址段。
- 校园网侧只直接服务控制节点；计算节点不配置校园网地址或第二条默认路由。

交换机出厂管理地址记录为 `192.168.1.253`，当前实际地址未知，不属于
`192.168.77.0/24` 的集群地址规划。部署和日常通信不得依赖该地址。

## 分配规则

1. 根据节点用途从对应静态地址段选择地址，不从 DHCP 地址池选择正式服务器地址。
2. 分配前检查路由器租约、inventory 和目标广播域，确认地址没有被占用。
3. 同时记录稳定主机名、静态地址和网卡 MAC；路由器固定租约只作为辅助管理。
4. Linux 主机自身保留静态网络配置，默认网关使用 `192.168.77.251`，子网掩码使用
   `/24`。
5. 使用预留地址或调整任何范围时，必须先更新本页，再修改设备配置和 inventory。
