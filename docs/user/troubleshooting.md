# 用户排障

## 任务一直排队

先查看任务和等待原因：

```bash
squeue -u "$USER"
scontrol show job <job-id>
```

检查是否申请了过多 CPU、GPU、内存或过长时限。GPU 分区按资源和调度优先级排队，合理申请通常比反复重提更快。

## Interactive App 无法连接

确认会话卡片中的任务仍处于运行状态，再查看会话日志。常见原因是工作目录不存在、请求的资源超过主机上限，或对应计算节点缺少应用运行时。

## GPU 不可见或数量不对

在作业内运行：

```bash
nvidia-smi -L
```

不要在登录会话中判断作业 GPU。GPU 应通过 Slurm 申请；如果作业内数量不对，请提交 Issue，并附分区、作业号和 `nvidia-smi -L` 输出。

## 磁盘空间不足

```bash
df -h /home /workspace /data
quota -s
```

先清理缓存和可再生成的中间文件，把长期数据移到 `/data`。不要删除别人的目录或绕过配额。

仍无法解决时，请提交 Issue，附上主机分区、作业号、复现步骤和相关日志；不要上传密码、私钥或数据库凭据。
