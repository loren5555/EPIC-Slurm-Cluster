# 用户文档

用户通常只需要记住一条路径：登录 OOD，选择目标主机和资源，提交任务，查看会话或日志。

1. [快速开始](quick-start.md)：第一次访问门户并运行一个短任务。
2. [提交任务](jobs.md)：Interactive Apps、Job Composer、Script 和 GPU 任务。
3. [排队与优先级](queue.md)：了解资源申请、预计时长和任务优先级。
4. [存储与环境](storage.md)：选择 `/home`、`/workspace`、`/data`，管理环境和缓存。
5. [其它功能](etc.md)：SSH 访问、命令行访问。
6. [排障](troubleshooting.md)：任务排队、会话失败、GPU 和磁盘问题。
